# 6,526条发言的内容分析

2026年10月24日启动、10月25日完成。原采集数据与标签002保留在`materials/`；本目录保存新增内容编码与统计。

## 文件

| 文件 | 内容 |
| --- | --- |
| `codebook.json` | 评价对象、态度与具体内容码的定义 |
| `batches/` | 按原顺序逐批读取正文及必要父链后记录的AI判断 |
| `corrections.json` | 评价边界、讨论对象、父链与范围的复核修订 |
| `focused-views.json` | 具体观点及早期批次新增内容码的一致性复核清单 |
| `coded-statements.json`、`逐条内容编码.csv` | 合并后的6,526条记录，保留原文、匿名作者、来源、时间、父链、历史字段及新编码 |
| `statistics.json` | 发言、作者、具体观点、来源与敏感性统计 |
| 三份分布CSV | `观点分布.csv`、`发言评价分布.csv`、`作者评价分布.csv` |
| `敏感性分析.csv` | 剔除最大来源、仅根评论、仅观众、排除疑似商业内容、同作者同文去重 |

`seq`为原分析JSON的1起始行号。旧`semantic_index`有缺失，因此本轮统一按`seq`引用，评论ID和原文字哈希保持不变。

## 统计

5,191条判为相关、1,208条不相关、127条相关性不明。按主要讨论副本及其原观察窗口过滤后纳入5,163条：深渊1,156条、剧诗1,124条、幽境2,883条。466条实际讨论对象与原视频分组不同；另有28条相关记录不在对应副本窗口内。

观点可多选；每条发言在同一内容码下计一次。比例以本副本相关发言为分母。作者数按匿名ID去重，作者观点可交叉；作者评价分布的四栏则互斥，合计等于相关作者总数。跨副本作者分别计数。没有从点赞推算赞同人数。

“轻松”“通过”“角色好用”“感谢攻略”与“认可副本体验”分别记录。新编码由AI完成并在同一轮工作中复核，尚无独立准确率或编码一致率检验。批次及修订记录提供判断轨迹，不能替代独立验证。

## 复算

在仓库根目录运行：

```bash
python scripts/analyze_content.py
python scripts/validate_content.py
```

汇总器只读取已保存的语义判断，不按关键词推断态度或重新采集。`docs/data/`中的三份CSV由汇总器同步生成，用于网页下载。
