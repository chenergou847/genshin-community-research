## 正文来源与重建方式

唯一编辑来源是本目录的`报告正文模板.md`和`报告引用摘录.json`，统计输入保持为`01_当前交付/编码分析数据.json`。从交接包根目录执行：

```powershell
python .\04_报告修订_20261019\生成修订报告.py
python .\04_报告修订_20261019\生成修订报告.py --check
python .\04_报告修订_20261019\核对修订.py
```

旧`write_full_corpus_report.py`仅转接到新生成器，支持`--check`；缺少新正文来源时明确报错，不回退到旧稿。原`finalize_full_corpus.py`、采集、抽样、编码或表格导出脚本均无需运行。

原`文件清单_SHA256.csv`、`导出校验.json`及`验证导出.py`记录的是修订前导出时点，继续保留，不覆盖历史凭据。旧验证器直接运行会报告上述有意更新的哈希差异；当前修订应结合新核对脚本和新增文件清单判读。新增校验不将原始采集完整性或编码准确率改写为通过。
