# 后续评论采集、抽样与审计的数据要求 v1

> 当前小样本版以17号方案及`采集工具/小样本使用说明.md`为准。本文件保留旧版字段与审计规范；其中全库枚举、400条相关发言及200/100审计规模只适用于旧研究目录。ID、隐私、语境和失败追溯原则仍沿用。

2026-10-17。与`12_本期评论双轨抽样方案_v1.md`配套。本文件是待实现的规格，不是爬虫代码；字段能否从正常访问方式取得，必须在实现阶段验证，不假定某接口必定可用。

## A. 采集前配置

| 字段组 | 必需内容 |
| --- | --- |
| 研究版本 | 方案版本、配置版本、修改原因、确认记录 |
| 三副本期次 | 模式ID、正式期次ID、国服开始时刻、当期识别特征、官方/实机证据位置、核验状态 |
| 时间 | 时区、共同T0、视频库冻结时间、原始发言清单冻结时间、实际抓取起止时间 |
| 检索 | 54个主组合、封存审计组A/B及其他发现路径、排序、日期分箱、正常终点定义 |
| 抽样 | 每副本400条有效相关发言；每副本200条固定原始审计；主统计每副本100条随机盲复核；小总体普查规则 |
| 随机性 | 冻结清单哈希、生成器名/版本、种子生成与登记时刻；不同用途使用不同随机流，禁止为结果平衡而更换种子 |
| 编码 | 相关性规则版本、主题代码本版本、冻结时刻、执行人及复核人 |

期次、T0或清单尚未冻结，不产生正式统计样本。初期试采、探索补样、正式概率样本和审计样本的用途标记必须可区分。

## B. 查询与发现日志：一条实际请求/页面一行

查询ID、通道（主/审计A/审计B/标签/投稿列表/旧候选）、关键词、排序、日期筛选、页码或游标、读取时间、页面或请求定位、返回视频ID、原始位置、重复标记、正常结束/触顶/失败状态、重试记录。

保留原始排序位置与去广告后的读取顺序，不相互替代。接口错误、加载未完成和真实零结果分开。查询日志应能证明执行了哪个范围，不能只输出一个最终视频列表。

## C. 视频库：一条视频一行

BVID及可用平台内部ID（字符串）、页面链接、标题、简介、标签、发布时间、读取时间、主UP公开账号ID、协作者及角色、素材/转载/引用关系、发现查询列表。

模式与期次可多标签；内容类型保留主类和附加标签；难度/配置/结果分别记录“作者自述”和“核验所得”。播放值保留原始展示值与可解析数值，不作为粉丝量。

核心审核字段：是否纳入、纳入/排除原因、本期内容证据位置、核验人、待核事项。待核视频不得混进正式视频库。零评论视频也保留行。

## D. 原始发言与线程

| 字段组 | 需要保存的内容 |
| --- | --- |
| 身份与归属 | 平台评论ID（如实际可用的rpid，先核验语义）、BVID、模式域、线程根ID、父发言ID、根/回复层级；ID均为字符串 |
| 作者关系 | 去标识化后的稳定作者ID、是否主UP/协作者、可识别的重复发言关系；报告不展示普通评论者昵称画像 |
| 时间与状态 | 创建时间戳及本地表示、首次/最后读取时间、正文保存状态、编辑时间（如可得）、删除/不可见/缺祖先状态 |
| 正文 | 原文、可见图片/表情/附件存在标记、可读性、点赞等读取时展示值、是否置顶；不得只存已挑选的负面片段 |
| 语境 | 所属视频、本期证据、祖先链、引用对象；窗口外祖先单独标为仅语境，不进窗口分母 |
| 采集来源 | 排序、页码/游标、原始返回位置、读取批次、是否重复返回、内容版本/哈希 |
| 处理状态 | 窗口内/外、去重键、格式错误、时间缺失、正文缺失、待复核项 |

同时保留根评论分页表及每个线程的回复分页表。不能只因根评论早于观察窗口就跳过其回复。平台不提供某字段时保留缺失及原因，不填零或编造ID。

置顶、作者发言和同文不同ID不在采集时删除。数据角色可多选，例如同一ID既属于统计样本又属于审计样本；原始记录只存一条，统计分母不因此重复。

## E. 完整性与冻结清单

每个视频/线程记录：页面显示总数及其可确认口径、实际枚举的唯一根/回复数、窗口内外数、正常分页终点、未完成页/线程、访问失败、未解释差额、最后核验时间。

输出至少包括：

- 视频审核全表和正式视频ID清单；
- 全部原始发言ID清单及相应正文保存状态；
- 每个副本的原始窗口发言清单；
- 仅语境材料清单；
- 去重与缺失日志；
- 视频库、发言清单与配置的哈希或等效不可混淆版本标识。

不能以页面总评论数和抓取数大致相等来单独判完整。对无法枚举的可见内容必须暴露失败；不能截掉问题视频再沿用原冻结库的代表性结论。

## F. 抽样及筛查日志：每个被处理ID一行

用途（探索、主统计、原始审计、编码复核、语境补充）、副本域、原始清单版本、种子/随机流、全排列位置、抽取时刻、相关性判定及证据、排除/不明原因、处理人、是否进入有效统计样本、入样顺序。

主统计只按照随机位置推进至400条定稿相关发言或全量耗尽，不接受手工替换ID，不因主题比例调整停止点。固定原始审计为独立固定数量抽取，不按照相关条数补足。

探索选取另记：所覆盖的类型/难度/时间/目标、为何补该来源、是否新UP、素材或攻略依赖、已读数量与新增信息。不得把这类选择伪装为等概率抽样。

## G. 编码、验证与报告

编码字段包括：期次相关性、是否可判断、难度及依据、本人经历/转述/推测/解释/玩梗、体验环节、问题提及、本人经历问题自述、条件/配置、行为、最终结果、情感、应对办法、反例、主题标签、缺失、代码本版本、原码与复核码、分歧解决依据。

保留主统计抽取前的代码本冻结记录。新增主题或准则变更留版本，不覆盖掉旧标签历史。

主题充分性日志应逐批列出：新来源、覆盖维度、既有主题数、新问题类型、新触发条件、新反例、未解决缺口、连续无新增计数、验证池来源及其是否被用于开发。重复读取同一来源不能算新批次验证。

比例结果逐副本逐主题输出：有效样本数、主题计数、估计比例、区间方法及上下限、是否普查、作者/线程集中度、根/回复结构、语境与相关性不明情况。多标签相加超过100%时说明原因。

## H. 实现后的验收用例要求（此阶段仅列要求）

| 用例 | 正确行为 |
| --- | --- |
| 页面只加载少量热评 | 不标记清单完整，不把前排结果当随机总体 |
| 窗口前根评论含窗口内回复 | 回复可进原始窗口清单，根评论作为语境保留 |
| 同一ID在多个排序重复出现 | 原文观测可留，发言清单只保留同一实体；计数不重复 |
| 同文不同ID、同作者多次发言 | 分别保留，并标记可能的重复表达或作者集中 |
| 一页加载失败或重复游标循环 | 明确失败/未完成，不伪造终点 |
| 页面总数含回复或历史发言 | 分开记录口径，不以显示数直接充当根评论总体量 |
| 随机抽中短句、正向或低互动发言 | 按相同相关性规则处理，不按价值感替换 |
| 正文/祖先丢失无法判定 | 留不确定与缺失，进入审计，不默认无问题 |
| 有效域不足400 | 全量核查并按普查报告，不跨期补齐 |
| 原15条名单之外发现合格视频 | 按统一规则入库；不受旧来源配额限制 |
| 统计种子重放 | 在相同清单、生成器、代码本条件下重建同一处理顺序 |
| 只能取得部分楼中楼 | 统计完整性不通过，不能继续宣称覆盖根和全部回复 |

未来脚本完成后，应先用小规模已知结构来源验证这些行为，再执行正式采集；本文件没有宣称任何接口或程序已通过这些检查。
