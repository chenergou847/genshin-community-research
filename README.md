# 原神高难副本社区观察

**社区在反馈什么，玩家期待怎样的高难副本？**

一项面向游戏产品运营的社区研究项目。观察深境螺旋、幻想真境剧诗与幽境危战的B站讨论，将视频发现、来源资格核验、评论保存、全量编码与线程阅读连接起来，解释社区反馈、态度分歧和挑战期待。

[阅读网页报告](https://chenergou847.github.io/genshin-community-research/) · [查看研究正文](report/报告.md) · [全链条材料目录](materials/00_材料总目录.md) · [隐私与公开版本说明](PUBLICATION.md)

| 研究规模 | 实际口径 |
| --- | --- |
| 固定视频来源 | 60条，三个副本各20条 |
| 已存评论正文 | 9,593个唯一ID；完整性门槛未整体通过 |
| 原窗口全量编码 | 6,526条，包含根评论与楼中楼 |
| 相关发言 | 4,698条；另有1,666条不相关、162条不明 |
| 人机分工 | 用户认可30条校准，其余6,496条为AI项目编码 |

## 三分钟了解这个项目

1. 先看[网页报告](https://chenergou847.github.io/genshin-community-research/)，重点阅读主要发现、三个副本和玩家期待。
2. 查看[研究方法与边界](METHODS.md)，理解为什么不能把发言条数当玩家人数、把高赞当赞同人数。
3. 从[全流程证据索引](materials/01_全流程证据索引.md)回到实际文件；[研究过程时间线](materials/02_研究过程时间线.md)连接51份阶段记录。
4. 如需核对具体结论，网页中的证据编号可查看26条原文及已存上文，再追溯到编码、正文主档和采集响应。

## 主要发现

- **深境螺旋：轻松与挑战不足并存。** 顺畅拿奖能带来满足，也有人主动降配后仍嫌缺乏挑战；具体敌人、机制理解和队伍适配影响局部难易体验。
- **幻想真境剧诗：规划有趣，不等于试错代价可接受。** 同一作者可以同时认可体系规划，并批评随机条件、回转空间和累计重开成本。拿主要奖励与冲满花是不同目标。
- **幽境危战：能否通过与愿不愿投入是两个问题。** 讨论涉及三队资源、打法复现、抽卡偏好与长期积累；对最高档应服务谁，线程内也没有统一答案。

报告由这些分歧归纳出五组条件性期待：可选择挑战目标、困难可理解和改进、规划有趣且试错代价可接受、角色偏好与积累有发挥空间、比较能说明真实条件。直接表达与研究推断分开呈现，没有新增态度占比，也没有将评论直接改写为产品改版清单。

## 展示的项目能力

| 能力 | 对应交付 |
| --- | --- |
| 明确研究对象与推断范围 | 固定窗口、视频纳排规则、已存正文范围及限制说明 |
| 记录选择与执行过程 | 有限检索、随机前缀资格核验、用户裁决与来源锁定 |
| 处理不完整社区数据 | 保存失败、计数差额、缺父链和规则变更，不以补抽掩盖问题 |
| 结合统计与语境解释 | 区分谈及主题和本人问题，结合父链、混合态度与反例 |
| 交付可追溯成果 | 原始档、编码、分析、引文、报告版本、脚本与哈希清单 |

本项目由人机协作完成：人类确定目标和关键边界、核定来源资格、认可30条校准并取消后续独立核验；AI辅助执行、编码、整理和撰写。未声称全量人工审阅、独立准确率验证、游戏实测或完整网络民族志。

## 本地阅读与核验

直接打开`docs/index.html`即可阅读，页面不依赖外部字体或图表库。原视频和GitHub材料链接需要联网。

```bash
python scripts/build_site.py
python scripts/validate_project.py
```

构建仅使用Python标准库，检查不会触发B站采集、重新抽样或重新编码。部署使用[GitHub Pages官方工作流](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。

## 结论边界

研究描述固定60条来源中已规范化保存的窗口正文，不能推断全B站或全体玩家。深渊和剧诗来源集中；20条发言受缺失祖先影响，981条附图未读；独立核验已由用户取消。点赞为窗口结束后的快照。全量编码与文件哈希校验均不等于语义准确率得到独立验证。
